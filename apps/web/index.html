  • file — document URL
  • type — lock detection
  • engine — renderer preference

  • loader — auto | blob | direct
  • credentials — omit | same-origin | include

Advanced config blob (?config=):
  • name — display name override
  • entry — archive member deep-link
  • entryBase — base URL for member links
  • code — { theme, lang }
  • image — { fullscreen }
  • video — { controls, autoplay, muted, loop, poster, info }
  • markup — { sandbox, baseUrl, gfm }
Advanced config (JSON)

The complete viewer config for the current filter. Universal knobs — file, type, engine, theme, loader, credentials, preflight — become query params; the rest — name, entry, entryBase, code, image, video, markup — become the base64url ?config= blob. Edit the JSON, then press Apply.

Why

  • Framework-agnostic. A vanilla TypeScript core; the React, Preact, Vue, Svelte and Solid wrappers are optional peers.
  • URL-first. One ?file=… query parameter renders a document — no application code.
  • Broad coverage. PDF, Office, images, video and code, with automatic fallback between engines.
  • Lean by default. No UI dependencies; the heavy engines load only when a document needs them.
