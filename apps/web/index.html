Why

  • Framework-agnostic. A vanilla TypeScript core; the React, Vue and Solid wrappers are optional peers.
  • URL-first. One ?file=… query parameter renders a document — no application code.
  • Broad coverage. PDF, Office, images, video and code, with automatic fallback between engines.
  • Lean by default. No UI dependencies; the heavy engines load only when a document needs them.
